Hafta 1

Diziler, işaretçiler ve dinamik bellek

  • Veri yapısı, verinin belleğe nasıl yerleşeceğini ve üzerinde hangi işlemlerin yapılacağını belirler. Program = algoritma + veri yapısı.
  • Primitif: int, float, char, pointer (dil doğrudan destekler). Primitif olmayan: dizi, liste, dosya; bunlar doğrusal (yığın, kuyruk, liste) ve doğrusal olmayan (ağaç, graf) diye ayrılır.
  • Bitişik (contiguous): parçalar bellekte yan yana, örnek dizi. Bitişik olmayan: parçalar dağınık, işaretçiyle bağlı, örnek bağlı liste.
  • Dizi: bellekte statik ayrılır, elemanlar aynı tipte ve ardışık adreslerde, indeksle erişilir. Dizinin ismi, ilk elemanını gösteren sabit işaretçidir.
  • C dizileri satır öncelikli (row-major) saklar: önce 0. satırın tamamı, sonra 1. satır… Fortran sütun öncelikli (column-major).

Adres hesabı (s = eleman boyutu, int için 4)

&A[i] = taban + i·s

&A[i][j] = taban + (i·SÜTUN + j)·s

&A[i][j][k] = taban + (i·M·N + j·N + k)·s // int A[L][M][N]

Örnek: int A[8] taban 0x4208A0B0 ise A[5] = 0x4208A0B0 + 5·4 = 0x4208A0C4. int d[5][6][7] taban 0x1000 ise &d[1][4][2] = 0x1000 + (42 + 28 + 2)·4 = 0x1120.

İşaretçi tipleri: int B[3][4]

Çıkmış soru · 20243 × 5 puan

a) C'de dizinin ismi ne anlama gelir? b) int dizi[]={1,2,3,4,5,6}; için dizi = dizi + 1 doğru mu? c) Dizi elemanlarının tipi neden aynı olmalı?

Çözümü göster

a) Dizinin ismi, dizinin ilk elemanının adresini tutan sabit işaretçidir.

b) Hayır. Dizi ismi sabit (değiştirilemez) işaretçi olduğu için ona atama yapılamaz; derleme hatası verir. (int *p = dizi; p = p + 1; ise geçerlidir.)

c) Elemanlar bellekte ardışık durur ve adres taban + i·eleman_boyutu ile hesaplanır; bu formülün çalışması için her elemanın aynı boyutta (aynı tipte) olması gerekir.

Defterden işaretçi notları

  • İşaretçiye işaretçi: int a = 10; int *ptr = &a; int **ptr2 = &ptr; → *ptr2 a'nın adresi, **ptr2 a'nın değeri (10). int ** tipine &a atamak tip uyuşmazlığıdır.
  • Tek elemanı fonksiyona değerle göndermek yeter, ama diziyi göndermek için ilk elemanın adresi gönderilir: f(x) ≡ f(&x[0]), ve *(x+2) ≡ x[2].
  • Bellek sızıntısı (memory leak): malloc ile ayrılan bloğun adresini kaybetmek; işin bitince free() ile geri ver.
  • Yerel değişkenin adresini döndürmek anlamsal hatadır (Evet diye sorulmuştu): fonksiyon bitince yerel değişkenin stack'teki yeri geri verilir, dönen adres geçersizdir.
  • malloc yer bulamazsa NULL döner; dönen void * tipe çevrilir: (int*)malloc(n*sizeof(int)).

Hafta 2

Matris çarpımı (statik ve dinamik)

  • A (m×n) · B (n×p) = C (m×p). Şart: A_sutun == B_satir; ayrıca C'nin boyutu m×p olmalı. Kod ikisini de kontrol edip hata mesajı basıyor.
  • C[i][j] = Σ A[i][k]·B[k][j] (k = 0..n−1). Üç iç içe döngü: O(m·n·p), kare matriste O(n³).
  • Statik 2B diziyi her boyutta çalışan fonksiyona int * olarak verip *(A + i*A_sutun + k) ile eriştik (çağrı: &A[0][0]).
  • Dinamik iki yol: int** (satır satır malloc, A[i][j] yazılabilir) veya int* tek blok (malloc(satir*sutun*sizeof(int)), erişim A[i*sutun+j]).
  • dot_carpim aslında eleman eleman çarpım yapar: x={3,4,0,6,1}, y={2,−1,4,−2,3} → z = 6 −4 0 −12 3.
void matris_carpimi(int *A, int A_satir, int A_sutun,
                    int *B, int B_satir, int B_sutun,
                    int *C, int C_satir, int C_sutun){
    int i, j, k;
    if(A_sutun != B_satir){ printf("boyutlar uyusmuyor"); return; }
    if(A_satir != C_satir || B_sutun != C_sutun){ printf("C uymuyor"); return; }
    for(i = 0; i < A_satir; i++)
        for(j = 0; j < B_sutun; j++){
            *(C + i*C_sutun + j) = 0;
            for(k = 0; k < A_sutun; k++)
                *(C + i*C_sutun + j) += *(A + i*A_sutun + k) * *(B + k*B_sutun + j);
        }
}

Koddaki örnek: A = {{1,0,2},{2,1,4},{5,1,0},{0,2,3}}, B = {{0,1},{2,4},{3,1}} → C = {{6,3},{14,10},{2,9},{13,11}} (ilk eleman: 1·0 + 0·2 + 2·3 = 6).

Hafta 3

Bağlı listeler (tek ve çift yönlü)

  • Liste düğümlerden oluşur; düğümler birbirine işaretçiyle bağlıdır. İlk düğümü gösteren işaretçiye liste başı denir, son düğümün sonraki'si NULL.
  • Düğümler malloc ile heap'te dinamik oluşturulur; malloc NULL dönerse "yer ayrılamadı" deyip çıkılır.
  • Liste başını değiştirebilecek her fonksiyon (başa ekle, sil, sırala, ters çevir, yok et) struct dugum **liste_basi alır; sadece okuyan (yazdır) struct dugum * alır.

// sil: önceki düğümü takip et
void liste_eleman_sil(int anahtar, struct dugum **liste_basi){
    struct dugum *temp = *liste_basi, *once;
    while(temp != NULL && temp->anahtar != anahtar){ once = temp; temp = temp->sonraki; }
    if(temp == NULL) return;                              // yok
    if(temp == *liste_basi) *liste_basi = temp->sonraki;  // baştaki siliniyor
    else once->sonraki = temp->sonraki;
    free(temp);
}
// sıralı ekle (aynı anahtar varsa ekleme)
void liste_sirali_ekle(int anahtar, struct dugum **liste_basi){
    struct dugum *a, *b = *liste_basi, *eklenen;
    while(b != NULL && b->anahtar <= anahtar){
        if(b->anahtar == anahtar) return;
        a = b; b = b->sonraki;
    }
    eklenen = dugum_olustur(anahtar);
    if(b == *liste_basi){ eklenen->sonraki = *liste_basi; *liste_basi = eklenen; }
    else { a->sonraki = eklenen; eklenen->sonraki = b; }
}
// ters çevir: a = çevrilmiş kısım, b = sıradaki düğüm
void liste_ters_cevir(struct dugum **liste_basi){

        *liste_basi = (*liste_basi)->sonraki;

Hafta 5 · en çok puan buradan

Ağaçlar ve ikili arama ağacı (BST)

  • Kök: ebeveyni olmayan düğüm. Yaprak: çocuğu olmayan. İç düğüm: yaprak olmayan (kök dahil). Kök hariç her düğümün bir ebeveyni vardır.
  • İkili ağaç: her düğümün 0, 1 veya 2 çocuğu. İkili arama ağacı: her düğümün anahtarı sol alt ağaçtaki tüm anahtarlardan büyük, sağ alt ağaçtakilerden küçük.
  • Yükseklik (derinlik): kökten en uzak yaprağa giden yoldaki düğüm sayısı (bu derste kenar değil düğüm sayılıyor: tek düğümlü ağaç = 1, boş ağaç = 0).
  • Dengeli ikili ağaç: her düğüm için sol ve sağ alt ağaçların yükseklik farkı en fazla 1. Dengeliyse ekleme/silme/arama O(log n); en kötü durumda (doğrusal ağaç) O(n).
  • Ekleme: kökten başla; küçükse sola, büyükse sağa git; yeni düğüm her zaman yaprak olarak eklenir. Aynı anahtar varsa eklenmez. Karmaşıklık O(h): dengeli O(log n), en kötü O(n).
void ekle(struct agac_dugum **kok, int anahtar){
    struct agac_dugum *d = *kok, *geri, *dugum;
    while(d != NULL){
        geri = d;
        if(anahtar < d->anahtar) d = d->sol;
        else if(anahtar > d->anahtar) d = d->sag;
        else return;                                 // zaten var
    }
    dugum = dugum_olustur(anahtar);
    if(*kok == NULL){ *kok = dugum; return; }        // ağaç boştu
    if(anahtar < geri->anahtar) geri->sol = dugum;
    else geri->sag = dugum;
}

  • Yaprak veya tek çocuklu: doğrudan sil, varsa çocuğu ebeveyne bağla.

    if(kok == NULL) return 0;
    tek = (kok->sol == NULL) != (kok->sag == NULL);   // tam olarak biri boşsa 1
    return tek + tek_cocuklu_dugum_sayisi(kok->sol)
               + tek_cocuklu_dugum_sayisi(kok->sag);
}

Hafta 6

Heap ve heap sort

  • Heap, dizi ile gerçekleştirilen özel bir dengeli ikili ağaçtır. Düğümler seviye seviye, en soldan başlayarak yerleşir; bir düğümün sol çocuğu yoksa sağ çocuğu da yoktur.
  • Max heap: her düğümün anahtarı çocuklarınınkinden büyük (kökte en büyük). Min heap: tersi. Ders max heap'e odaklanıyor.
  • Heap ikili arama ağacı değildir: sol < kök < sağ sırası yok, sadece ebeveyn > çocuk. ("Heap dengeli BST midir?" → Hayır.)

İndeks formülleri (kök = 0, n eleman)

sol(i) = 2i + 1 sağ(i) = 2i + 2 ebeveyn(i) = (i − 1) / 2

son iç düğüm = n/2 − 1 yapraklar = n/2 … n−1 (⌈n/2⌉ tane)

void buble_down(struct heap *heap, int index){
    int sol = 2*index + 1, sag = 2*index + 2, buyuk;
    struct dugum temp;
    while(sol < heap->eleman_sayisi){
        buyuk = sol;                                       // büyük çocuğu seç
        if(sag < heap->eleman_sayisi && heap->dizi[sag].key > heap->dizi[sol].key) buyuk = sag;
        if(heap->dizi[buyuk].key < heap->dizi[index].key) break;   // heap özelliği tamam
        temp = heap->dizi[index]; heap->dizi[index] = heap->dizi[buyuk]; heap->dizi[buyuk] = temp;
        index = buyuk; sol = 2*index + 1; sag = 2*index + 2;
    }
}
void heapify(struct heap *heap){
    int i;
    for(i = heap->eleman_sayisi/2 - 1; i >= 0; i--) buble_down(heap, i);
}
void buble_up(struct heap *heap, int index){
    int p = (index - 1)/2;   // C'de (0-1)/2 = 0 olur; kökte a[0] < a[0] yanlış → döngü biter
    struct dugum temp;
    while(p >= 0 && heap->dizi[p].key < heap->dizi[index].key){
        temp = heap->dizi[p]; heap->dizi[p] = heap->dizi[index]; heap->dizi[index] = temp;
        index = p; p = (index - 1)/2;
    }
}
void delete_max(struct heap *heap){
    struct dugum d;
    if(heap->eleman_sayisi > 1){
        d = heap->dizi[0];
        heap->dizi[0] = heap->dizi[heap->eleman_sayisi - 1];
        heap->dizi[heap->eleman_sayisi - 1] = d;    // max dizinin sonunda kalır
        heap->eleman_sayisi--;
        buble_down(heap, 0);
    }
}

Sarı düğümler yapraklar: en küçük bunlardan biri

int minimum_anahtari_bul(struct heap *heap){
    int i, n = heap->eleman_sayisi, min;
    if(n == 0) return SENTINEL;
    min = heap->dizi[n/2].anahtar;           // ilk yaprak
    for(i = n/2 + 1; i < n; i++)             // sadece yapraklara bak
        if(heap->dizi[i].anahtar < min)
            min = heap->dizi[i].anahtar;
    return min;                              // ⌈n/2⌉ − 1 karşılaştırma
}
